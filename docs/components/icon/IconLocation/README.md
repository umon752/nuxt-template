# IconLocation

位置裝飾圖示，使用 `currentColor` 繼承父層文字顏色。

原始碼：[IconLocation.vue](../../../../app/components/icon/IconLocation.vue)

## 使用方式

    <span aria-label="公司地址">
      <IconLocation class="size-6" />
    </span>

元件沒有 Props、Slots 或 Events。圖示為 aria-hidden，若圖示承載資訊意義，外層內容必須提供可理解的文字或 accessible name。
