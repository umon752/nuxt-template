## Inventory every used font

The local Text style catalog is not a complete font inventory. Text may use a font directly, use a remote/unpublished Text style, contain mixed fonts, or live inside an instance/component. Scan actual `TEXT` nodes on every page.

1. Make one cheap read-only `use_figma` call that returns `figma.root.children.map(page => ({ id: page.id, name: page.name }))`.
2. In the next assistant turn, issue one `use_figma` call per page in parallel. Each script must call `await figma.getNodeByIdAsync(PAGE_ID)`, then `await figma.setCurrentPageAsync(page)` exactly once.
3. On that page, use `page.findAllWithCriteria({ types: ['TEXT'] })`. Do not use `figma.root.findAll` and do not scan only the current selection.
4. For every `TextNode`, call `getStyledTextSegments(['fontName'])`. Record every segment's exact `fontName.family` and `fontName.style`, plus page ID/name, node ID/name, visibility, text-style ID when available, segment character count, and the node's usage count. Keep hidden nodes in the inventory and mark them `hidden`; they are still design usage unless the user excludes them.
5. Deduplicate by exact family/style pair, then aggregate by family. Keep both node counts and styled-character counts so the global-family heuristic is auditable.
6. Read local Text styles and `getStyleConsumersAsync()` separately. Mark a style as `used` only when it has a consumer; mark an unconsumed style as `defined-but-unused`. A style definition alone must not cause a Google Fonts import or a global font change.

If a page scan fails, report the page and error. Do not claim the inventory is complete or proceed with a base-family change until every page has been scanned successfully.

## Verify and link Google Fonts CDN

Use read-only network access to the official Google Fonts CSS2 endpoint or official Google Fonts metadata. Do not add an API dependency, download font binaries, or use a third-party font mirror.

For each used family:

1. Check that the exact family exists on Google Fonts. Preserve the family spelling returned by Figma for CSS, while using the URL-encoded family name in the request.
2. Check every used weight and italic/non-italic variant. A family being available does not guarantee that every requested variant exists.
3. Mark each family/variant `google`, `local`, `unavailable`, or `variant-unavailable`.
4. For available Google families, create a deterministic Google Fonts CSS2 stylesheet URL with only the used variants and `display=swap`, for example:

   ```ts
   {
     rel: 'stylesheet',
     href: 'https://fonts.googleapis.com/css2?family=Example+Sans:ital,wght@0,400;0,700;1,700&display=swap',
   }
   ```

5. Write the CDN entries in `nuxt.config.ts` under `app.head.link`, using a managed block and preserving unrelated/manual links:

   ```ts
   // Figma Google Fonts — generated by sync-figma-nuxt-tokens
   {
     rel: 'preconnect',
     href: 'https://fonts.googleapis.com',
   },
   {
     rel: 'preconnect',
     href: 'https://fonts.gstatic.com',
     crossorigin: '',
   },
   {
     rel: 'stylesheet',
     href: 'https://fonts.googleapis.com/css2?family=Example+Sans:ital,wght@0,400;0,700;1,700&display=swap',
   },
   // End Figma Google Fonts
   ```

6. Deduplicate by family and variant set. If an existing Google Fonts link is unmarked, preserve it unless it is clearly a previous generated entry or an explicit project mapping. Never add a CSS `@import` to `_theme.css`.
7. Check the repository CSP before writing. Add `https://fonts.googleapis.com` to `style-src` and `https://fonts.gstatic.com` to `font-src` only when missing; preserve all unrelated hosts and directives.

If Google Fonts has no matching family, explicitly tell the user the exact family, the pages/nodes that use it, and whether a local font asset or a fallback choice is needed. If the unavailable family is the selected global family, treat the sync as `blocked` until the user decides. For a non-base family, keep it in the commented font list and report that its Text style utility will need manual font sourcing.

## Select the global font

Select `--font-base` using this order:

1. `font.baseFamily` or an equivalent explicit project override.
2. The family used by the most-consumed Text style named `Body`, `Body/*`, `Paragraph`, `Base`, or `Default`.
3. The family with the greatest total styled-character count, then greatest node count.
4. A deterministic first family by page order and node order only as a last resort.

Always show the selected family, its evidence, usage counts, and rejected alternatives in the mapping preview. Preserve the existing fallback suffix when updating `--font-base`; if none exists, use `sans-serif` unless the user explicitly chooses another generic family.

Use this deterministic mapping for common Figma `fontName.style` values; include `font-style: italic` when the style contains `Italic`:

| Figma style name             | CSS `font-weight` |
| ---------------------------- | ----------------: |
| `Thin`, `Hairline`           |             `100` |
| `Extra Light`, `Ultra Light` |             `200` |
| `Light`                      |             `300` |
| `Regular`, `Normal`, `Book`  |             `400` |
| `Medium`                     |             `500` |
| `Semi Bold`, `Demi Bold`     |             `600` |
| `Bold`                       |             `700` |
| `Extra Bold`, `Ultra Bold`   |             `800` |
| `Black`, `Heavy`             |             `900` |

Treat a custom style name, variable-font axis, or family-specific weight as `needs-confirmation` unless its numeric weight is exposed by the source or an override.

Under the active `--font-base` declaration, add a generated comment block for every other used family and every unavailable family. Keep these suggestions commented so they do not become global defaults:

```css
--font-base: 'Example Sans', sans-serif;

/* Other Figma font families — manual review */
/* --font-display: '<display-family>', serif; */
/* --font-brand: '<brand-family>', sans-serif; */ /* unavailable on Google Fonts */
```

Do not replace a base family already chosen by a project override. If the source has multiple equally valid families and no Body-like style or override, ask the user before writing.

## Map used font sizes

The active `/* font-size */` section in `_theme.css` must contain only font sizes observed in actual Text node segments or consumed Text styles.

- Treat Figma `fontSize` as pixels and preserve the value as `<number>px`.
- Apply explicit `textSizeAliases` or Text style aliases first.
- Canonicalize heading names: `H1`, `Heading 1`, and `Header 1` may use `--text-h1`; apply the same rule to levels 2–6. `Body` may use `--text-body`.
- For an unstyled size without a semantic alias, use a deterministic token such as `--text-size-14: 14px` or `--text-size-13-5: 13.5px`.
- If several used styles share one size, reuse one size token where an alias makes the relationship clear; do not create duplicate values without a reason.
- Compare existing starter tokens against both Figma usage and repository references. Keep a token active when it is used by the repository even if Figma does not use it, and report the conflict. For an unreferenced, unused starter token, move it to a labelled commented block below the active section instead of deleting it.
- Do not infer sizes from screenshots, frame dimensions, or a style that has no consumer.

The preview must list active size tokens, commented legacy tokens, source nodes/styles, and any repository references that prevent commenting a token.

## Generate Text style utilities

Create one class for each consumed Text style in `app/assets/css/utilities/_utilities.css`. Use a managed block so subsequent syncs replace only generated classes:

```css
/* Figma Text styles — generated by sync-figma-nuxt-tokens */
@layer utilities {
  .u-h1 {
    font-family: var(--font-base);
    font-size: var(--text-h1);
    font-weight: 700;
    line-height: normal;
  }
}
/* End Figma Text styles */
```

The real file already has an `@layer utilities` block. Add the generated classes inside that existing layer; do not create an unnecessary nested or duplicate layer. Keep all existing manual utilities intact.

Normalize class names as follows:

- `H1`, `Heading 1`, `Header 1` → `.u-h1`; apply the same rule for levels 2–6.
- `Body` → `.u-body`.
- Other names → `.u-` plus lowercase kebab-case, with an explicit `textStyleAliases.<source>.className` taking precedence.
- Detect collisions with an existing class or another Text style. Ask for an alias instead of overwriting a manual class.

For each class, include only properties that can be expressed faithfully in CSS:

| Figma property                | Utility declaration                                                                                                                                    |
| ----------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `fontName.family`             | `font-family`; use `var(--font-base)` when it is the selected base family, otherwise use an available exact family/fallback or report a missing source |
| recognized `fontName.style`   | numeric `font-weight` and `font-style: italic` when applicable                                                                                         |
| `fontSize`                    | `font-size: var(--text-...)`                                                                                                                           |
| `lineHeight: AUTO`            | `line-height: normal`                                                                                                                                  |
| fixed pixel line height       | `line-height: <value>px`                                                                                                                               |
| percentage line height        | `line-height: <value>%` when the Figma unit is CSS-compatible                                                                                          |
| pixel letter spacing          | `letter-spacing: <value>px`                                                                                                                            |
| supported text case           | `text-transform` or the appropriate CSS text casing property                                                                                           |
| `UNDERLINE` / `STRIKETHROUGH` | `text-decoration`                                                                                                                                      |

Do not use Tailwind `@apply` for values that may be invalid or generated from Figma. Plain CSS declarations make the source mapping explicit and allow `line-height: normal` for Figma Auto.

## Report CSS gaps

Include a decision table in the preview for every source property that is not written. At minimum, check:

- Figma `letterSpacing.unit: PERCENT`: CSS `letter-spacing` does not have a broadly interoperable percentage value. Do not emit `letter-spacing: -2%`; propose a fixed pixel conversion or manual CSS decision.
- `leadingTrim` values other than `NONE`: CSS text-box trimming is not broadly interoperable; report it rather than pretending it is equivalent to line-height.
- `paragraphSpacing`, `listSpacing`, and `hangingList`: these are not portable Text style declarations in a single CSS class; report the required component/list-level treatment.
- `hangingPunctuation`: map only when the project's browser support policy permits it; otherwise report it.
- `SMALL_CAPS` or custom text-case values: report when no faithful browser-supported mapping exists.
- An unrecognized Figma font style or a Google-unavailable family/variant: report the exact missing mapping.
- Figma fills, mixed text properties, progressive effects, and other style data that do not belong in a typography class: preserve them in the inventory and mark them `report-only`.

`lineHeight: AUTO` is not a gap: always write `line-height: normal` in the corresponding utility class.

## Preview and write safely

Before changing CSS, show:

1. Every used family, variant, usage evidence, and Google/local availability.
2. The selected `--font-base` family and alternatives.
3. Google Fonts CDN links, preconnects, and CSP changes to add, update, or leave unchanged.
4. Active font-size tokens and legacy tokens to comment or preserve because of code references.
5. Every Text style class, its CSS declarations, and its normalized class name.
6. Unsupported or ambiguous properties requiring a user decision.

After confirmation:

- Replace only the marked Google Fonts CDN block in `nuxt.config.ts` and the Text style utility block.
- Update the existing `/* font-family */` and `/* font-size */` sections in `_theme.css` without adding `@import` rules or reformatting unrelated CSS.
- Preserve all manual declarations and comments outside generated blocks.
- Format `nuxt.config.ts`, `_theme.css`, and `_utilities.css`, run `git diff --check`, inspect the full diff, and report any unavailable fonts or unhandled CSS properties. Never modify Figma, stage, commit, or push as part of this skill.
